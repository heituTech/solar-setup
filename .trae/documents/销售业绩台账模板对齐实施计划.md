# 销售业绩台账模板对齐实施计划

## Context

现有 MVP 已打通「线索→勘测→报价→订单→项目→设备→验收→回款→月度结算」链路，但 finance 的订单台账、月度结算表与用户提供的「销售业绩记录模板.xlsx」不一致：
模板要求 25 列订单台账（成交日期、客户类型、订单类型、产品与配置、定金/尾款及到账、两阶段提成、已发/待发、交付日期、转介绍等）、勘测记录表、以及含首单奖/转介绍奖/勤奋奖/扣款分项的月度结算表。

目标：把模板业务字段落到真实投影数据上，并在 finance 提供按模板结构导出 xlsx 的能力，同时保持既有链路与 e2e 不回归。

业务规则来源：`.trae/documents/全链路业务工作台MVP实施计划.md` L205-L214
- 合同 USD 业绩基数：`<1500` 零售、费率 8%；`1500–5000` 工程 4%；`>5000–15000` 工程 5%；`>15000` 工程 6%
- 底薪 300、首单奖 20、转介绍奖 1%（按净回款）、当月有效勘测 ≥15 次勤奋奖 50
- 提成两阶段：实际回款达 50% 产生 30%（`1 - remaining_rate`），达 100% 且验收后产生 70%（`remaining_rate`）
- 本人提成与转介绍奖只取其一；退款不静默冲销，需显示应追回
- 定金默认为合同额 50%，尾款为剩余部分，由多笔回款累计判定到账

## 后端改动

### 1. 迁移（只新增 002，禁止改 001，迁移有 checksum 校验）

**`services/sales-service/database/migrations/002_ledger_template.sql`**
- `customers` 增加 `customer_type VARCHAR(20) NOT NULL DEFAULT 'retail'`（retail/engineering）
- `surveys` 增加 `created_by_name VARCHAR(120) NULL`（勘测记录导出需要销售员姓名，sales 无身份库）

**`services/finance-service/database/migrations/002_ledger_template.sql`**
- `order_ledger` 增加模板列：`deal_date DATE`、`customer_phone`、`customer_type`、`order_type`、`product_config VARCHAR(1000)`、`discount_approver`、`deposit_amount`、`deposit_received TINYINT(1)`、`balance_amount`、`balance_received TINYINT(1)`、`deposit_commission`、`settlement_commission`、`paid_commission`、`delivery_date DATE`、`referral_flag TINYINT(1)`、`referral_name`、`note`
- `settlements` 增加：`deposit_commission_total`、`settlement_commission_total`、`first_order_reward`、`referral_reward`、`diligence_reward`、`champion_reward`、`deduction_total`、`survey_count`
- 新建 `survey_records`：`survey_id` 唯一、`customer_id`、`customer_name`、`salesperson_id`、`salesperson_name`、`address`、`photo_refs`、`confirm_method`、`requirement_summary`、`is_valid`、`note`、`survey_date DATE`
- `compensation_config`：`survey_reward` 默认 50、`first_order_reward` 默认 20，并把现存 0 值更新为模板默认值

执行：`npm run migrate:sales`、`npm run migrate:finance`。

### 2. sales-service

- **`app/controller/quotes.js` / convert**：
  - 新增 `rateForAmount(amount)`：按上述金额带返回 `{ order_type, rate }`；参考 `num/reference` 工具已在本文件
  - `customer_type` 取 `customer.customer_type || 'retail'`
  - `referral = customer.source === 'referral'`；转介绍订单 `commission_rate = 0`（提成与转介绍奖只取其一）
  - `product_config` = `items` 的 `name×qty` 以 `; ` 拼接
  - `ORDER_CONVERTED` payload 增加：`customer_phone/customer_type/order_type/product_config/discount_approver(取 quote.notes 可选)/referral/referral_name/deal_date`
- **`app/controller/surveys.js`**：
  - `create` 写入 `created_by_name = ctx.state.user.name`
  - `review` 改为 `withTransaction`：更新状态后 `enqueueEvent(EVENTS.SURVEY_REVIEWED, destinations: ['finance'])`，payload 携带 `survey_id/customer_id/customer_name/created_by/created_by_name/address/photo_refs/confirm_method/requirement_summary/is_valid/survey_date/note`（后 5 项优先取 `payload` JSON 字段）
  - 引入 `withTransaction/enqueueEvent/EVENTS`
- **`app/controller/customers.js`**：`create/update` 支持 `customer_type`；列表/详情天然返回
- **`app/router.js`**：无需新增路由（沿用现有）

### 3. finance-service

- **`app/controller/internal.js`**
  - `ORDER_CONVERTED`：插入 ledger 时写入全部模板列；`deposit_amount = 50% 合同额`、`balance_amount = 余额`、`deposit_commission = 总提成 × (1 - remaining_rate)`、`settlement_commission = 总提成 × remaining_rate`（`remaining_rate` 读 `compensation_config`）；`deal_date` 取 payload 或当天
  - `PROJECT_ACCEPTED`：同时写 `delivery_date = DATE(accepted_at)`
  - 新增 `SURVEY_REVIEWED` 分支：`INSERT IGNORE INTO survey_records ...`
- **`app/controller/payments.js`**
  - 回款后按累计回款重算 `deposit_received`（≥定金）与 `balance_received`（≥合同额）
  - 保留现有 outbox 事件
- **`app/controller/settlements.js` / generate**
  - 按用户汇总当月已验收且结清的 ledger：`deposit_commission_total`、`settlement_commission_total`、`commission_total = 两者之和`
  - 首单奖：`first_order_reward`（该用户此前无已结算记录时取配置值）+ `award` 类型调整
  - 转介绍奖：`referral_rate × SUM(received_amount WHERE referral_flag=1)`
  - 勤奋奖：当月 `survey_records.is_valid=1` 数量 ≥15 时取配置 `survey_reward`
  - 销冠奖保留字段默认 0；`deduction_total = penalty + recover`
  - `adjustment_total = 首单 + 转介绍 + 勤奋 + 销冠 - 扣款`；`payable = base_salary + commission_total + adjustment_total`
  - `base_salary` 缺省 300；`survey_count` 写入快照
  - settlement_items 增加 reward/deduction 明细行
  - **pay**：回写 `ledger.paid_commission += commission_amount`，保留 `settled_at`
- **`lib/finance.js`**：`toLedger` 增加新金额字段的 `num()` 转换
- **新增 `app/controller/export.js`**
  - `exportLedger(ctx)`：读取 `period=YYYY-MM`，查询 ledger、survey_records、settlements
  - 用 `exceljs` 生成 4 个工作表：`说明`、`订单台账`（25 列模板顺序）、`勘测记录`（9 列）、`月度结算`（模板列）
  - 设置列宽/表头加粗/金额数字格式；返回 buffer 并设置 `Content-Disposition: attachment; filename="ledger-YYYY-MM.xlsx"`
- **`app/router.js`**：`GET /pv/api/workbench/ledger/export`，`auth + finance` 角色
- **`package.json`**：增加 `exceljs` 依赖并安装；若安装失败，退化为本地最小 xlsx 写入模块（zlib 手工 zip），不阻塞功能
