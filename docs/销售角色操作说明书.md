# HEITU ERP 销售角色操作说明书

适用角色：**销售（salesperson）**、**销售经理（sales_manager）**
适用系统：https://www.heitu.tech/pv/
文档日期：2026-11-18

---

## 一、登录与基本规则

### 1.1 登录

1. 打开 https://www.heitu.tech/pv/login 。
2. 输入「用户名 / 邮箱 / 手机号」和密码，点击**登录**。
3. 登录页右上角可切换界面语言（中文 / English 等 10 种）。

### 1.2 会话与安全规则

| 规则 | 说明 |
|---|---|
| 登录有效期 | 12 小时，到期后自动回到登录页，需重新登录 |
| 主动退出 | 点击右上角头像 → 退出；退出后当前登录凭证立即失效 |
| 密码错误锁定 | 同一账号 15 分钟内连续输错 5 次，锁定 15 分钟（页面提示请求频繁） |
| 页面加载保护 | 每次查询数据库时页面会出现半透明遮罩，数据加载完成前无法进行下一步操作，属正常现象 |

### 1.3 数据可见范围

- **销售（salesperson）**：只能看到**自己名下**的客户、勘测、报价、订单、项目、工单、台账和薪酬记录。
- **销售经理（sales_manager）**：可看到自己和直属下属销售的数据。
- 账号关联的上级由管理员在「系统管理 → 用户」中设置。

> 若打开列表发现是空的，先确认筛选条件，再确认该数据是否登记在自己名下。

## 二、界面总览

左侧菜单对所有员工显示相同条目，但**按钮和操作会按角色、数据状态自动隐藏或禁用**。销售常用的有：

| 菜单 | 销售可做的事 |
|---|---|
| 概览 | 查看 KPI、最近订单、快捷入口 |
| 客户 | 新建、编辑、客户 360 查看 |
| 现场勘测 | 新建勘测、提交审核 |
| 报价 | 新建报价、提交审批、接受、转订单 |
| 订单 | 只读查看（提成比例由经理/财务维护） |
| 项目 | 只读查看进度、设备、时间线 |
| 工单 | 新建工单、查看处理进度 |
| 台账 | 只读查看回款与佣金 |
| 月度薪酬 | 只读查看本人结算单 |
| 产品目录 | 查看；新增/修改需提交审批 |
| 系统管理 | 审批页只能查看自己提交的申请，不能审批 |
| 我的案例 | 新建案例、分享链接、删除 |

业务主线：

```
客户建档 → 现场勘测 → 报价 → 提交审批 → 客户接受 → 转订单
        → 交付/安装（项目）→ 最终验收 → 财务回款 → 月度提成结算
```

## 三、客户管理

菜单：**客户**

### 3.1 查询

- 顶部可按**关键字**（姓名/手机/地区等）和**状态**筛选，点「查询」；点「重置」清空条件。
- 列表每页 10 条，底部可翻页、跳页，并显示总条数。
- 列表字段：姓名、手机、地区、来源、客户类型、负责人、状态、日期。

### 3.2 新建客户

点击右上角**新建客户**，填写：

| 字段 | 说明 |
|---|---|
| 姓名 | 必填 |
| 手机 / 邮箱 | 用于后续联系与登录账号关联 |
| 区域 / 地址 | 地址用于勘测和交付 |
| 来源 | 转介绍 / 网站 / 上门 / 手工录入 |
| 客户类型 | 零售（retail）/ 工程（engineering） |
| 状态 | 线索 / 已确认 / 已成交 / 已流失，新建默认「线索」 |
| 备注 | 补充说明 |

保存后客户归属当前销售。

### 3.3 客户 360

在列表点**客户 360**，右侧抽屉集中展示该客户的：

- 基本信息
- 勘测记录（状态、屋顶类型、屋顶面积、日期）
- 报价记录（报价编号、金额、状态）
- 订单记录（订单编号、金额、未回款、状态）

用于拜访前快速回顾客户全貌，不需要再逐页查找。

### 3.4 编辑客户

点**编辑**修改信息。客户在「已成交」后仍可修改联系方式、地址等资料；状态由业务判断维护（如客户最终未成交改为「已流失」）。

## 四、现场勘测

菜单：**现场勘测**

### 4.1 新建勘测

点击**新建勘测**，填写：

| 字段 | 说明 |
|---|---|
| 选择客户 | 必填，可按关键字搜索 |
| 地址 | 默认与客户地址一致，可修改为现场地址 |
| 屋顶类型 | 屋顶（rooftop）/ 地面（ground） |
| 屋顶面积 | 单位平方米 |
| 月用电量 | 用于方案与容量测算 |
| 备注 | 现场情况、限制条件等 |

保存后状态为**草稿**。

### 4.2 提交审核

草稿状态下点**提交审核**，状态变为**已提交**，等待工程师审核：

- 审核通过 → **已审批**
- 审核驳回 → **已驳回**，请按驳回意见修改后重新创建/提交

> 审核按钮仅工程师/经理可见，销售只能提交，不能自行审批。

## 五、报价

菜单：**报价**

### 5.1 新建报价

点**新建报价**，填写：

- **客户**：必填
- **报价明细**：每行填写「名称 / 数量 / 单价」，可**添加明细**或**删除**行；至少保留一行名称且单价大于 0
- **备注**：折扣原因、特殊约定等（会随订单传递）
- 合计金额由系统自动计算，币种默认 USD

保存后状态为**草稿**。系统目前不提供报价编辑入口，提交前请核对客户、明细名称、数量和单价。

### 5.2 报价状态流转

```
草稿(draft)
  └─ 提交审批 → 待审批(pending_review)
        ├─ 经理审批通过 → 已审批(approved)
        │     └─ 客户确认 → 已接受(accepted)
        │           └─ 转订单 → 已转订单(converted)
        └─ 经理驳回 → 已驳回(rejected)（需重新创建报价）
```

| 当前状态 | 销售可执行的按钮 | 说明 |
|---|---|---|
| 草稿 | 提交审批 | 提交前请确认明细无误，无编辑入口 |
| 待审批 | 无 | 等待销售经理审批 |
| 已审批 | 接受 | 客户确认成交后点击 |
| 已驳回 | 无 | 需重新创建报价 |
| 已接受 | 转订单 | 生成正式订单 |
| 已转订单 | 无 | 流程结束 |

### 5.3 转订单

在**已接受**状态点**转订单**，系统自动完成：

1. 生成订单号（SO 开头），订单进入**初始化中**；
2. 客户状态自动改为**已成交**；
3. 按订单金额自动套用提成比例；
4. 通知交付、财务开始后续流程。

**提成比例规则（自动计算）：**

| 订单金额 | 订单类型 | 提成比例 |
|---|---|---|
| < 1500 | 零售 | 8% |
| 1500 – 5000 | 工程 | 4% |
| 5000 – 15000 | 工程 | 5% |
| > 15000 | 工程 | 6% |
| 转介绍客户 | — | 0% |

> 转介绍客户（来源=转介绍）不计算销售提成，需在客户资料中如实填写来源。

## 六、订单（只读）

菜单：**订单**

- 列表字段：订单编号、客户、订单金额、已回款、未回款、提成比例、状态、日期。
- 支持关键字（订单号/客户）与状态筛选，每页 10 条。
- **销售没有编辑按钮**：订单金额、提成比例由经理/财务维护，如需调整请联系经理。
- 订单状态：**初始化中 → 已验收**（交付完成后由项目验收推进）。

---

## 七、项目（只读）

菜单：**项目**

- 列表字段：订单编号、客户、地址、电气工程师、结构工程师、状态。
- 点**查看**可打开展示抽屉，查看：
  - 项目基本信息与状态
  - 设备清单（名称、型号、序列号、数量、状态）
  - 项目时间线
- 状态：**待分配 → 初始化中 → 交付中 → 已验收**。
- 指派工程师、推进进度、设备登记、最终验收均由交付/工程角色操作，销售只读。
- 用途：向客户同步安装进度、设备到货情况。

## 八、工单

菜单：**工单**

### 8.1 新建工单

点**新建工单**，填写：

| 字段 | 说明 |
|---|---|
| 选择项目 | 选填，可按「订单号 · 客户」搜索 |
| 标题 | 简要描述问题，如「逆变器报警」 |
| 描述 | 详细现象、发生时间 |
| 优先级 | 低 / 普通 / 高 / 紧急 |

### 8.2 跟踪

- 状态：**待处理 → 处理中 → 已解决 → 已关闭**。
- 工单列表对员工开放，可查看全部工单的处理进度；「推进 / 解决 / 关闭」按钮由交付/售后角色操作。

## 九、台账（只读）

菜单：**台账**

用于核对成交与回款，排查客户欠款。主要内容：

- 成交日期、订单编号、客户、电话、客户类型、订单类型
- 产品配置、负责人
- 订单金额、定金、尾款、已回款、未回款
- 应结佣金、已发佣金、待发佣金
- 交付日期、验收时间、转介绍信息、状态

支持关键字与状态筛选。台账中的回款、佣金调整由财务操作，销售只读。

## 十、月度薪酬（只读）

菜单：**月度薪酬**

- 列表字段：月份、姓名、底薪、定金提成、结算提成、提成小计、首单奖励、转介绍奖励、勤奋奖励、扣罚、合计、发放状态。
- 只能看到**本人**的结算记录。
- 状态：**草稿 → 已确认 → 已付款**。
- 「生成结算 / 确认 / 发放」按钮仅财务与管理员可见。
- 点**详情**可查看该月每笔订单的提成构成和奖励/扣罚明细。

如对金额有疑问，请携订单号联系财务核对，销售端不能修改。

## 十一、产品目录

菜单：**产品目录**

- 可查看全部产品（品类、型号、名称、规格、价格、单位、状态）。
- 销售**新增或修改产品时会提交审批**，页面提示「已提交审批」，产品在经理审批通过后才生效，不会立即改动目录。
- 审批结果可在「系统管理 → 审批」中查看（只能看到自己提交的申请）。

## 十二、系统管理（审批查看）

菜单：**系统管理**

- 「用户」页签：销售可查看列表，但**新建/编辑用户仅管理员可见**。
- 「审批」页签：销售只能看到**自己提交**的审批（如产品新增/修改、报价折扣），状态为**待处理 / 已审批 / 已驳回**。
- 审批操作（通过/驳回）仅超级管理员和销售经理可执行，且不能审批自己提交的申请。

## 十三、我的案例

菜单：**我的案例**（/cases）

1. 点**新建**，填写案例名称、使用场景、系统模式（离网 / 混合 / 并网）、备注。
2. 点**分享**复制公开链接，可直接发给客户查看。
3. 点**删除**移除案例。
4. 支持关键字与状态筛选，每页 10 条。

## 十五、常见问题

**1. 列表是空的，但我确定有数据**
- 检查顶部筛选条件与状态是否过窄，点「重置」；
- 检查是否在第 2 页之后；
- 确认数据负责人是否是自己（销售只能看自己名下的数据）。

**2. 看不到「提交审批 / 接受 / 转订单」按钮**
按钮按状态显示：只有草稿能提交，只有已审批能接受，只有已接受能转订单。状态不对时按钮不会出现。

**3. 提示「items_required」或无法保存报价**
报价至少需要一行明细，且名称不能为空、单价必须大于 0。

**4. 提示「quote_not_approved」/「quote_not_accepted」**
报价还没走完审批或客户确认流程，不能接受或转单，请先提交审批。

**5. 提示请求过于频繁（429）**
账号因连续输错密码被临时锁定 15 分钟，请等待后重试；忘记密码请联系管理员重置。

**6. 操作后提示无权限（403）**
该操作不属于销售角色（例如审批报价、修改提成比例、指派工程师），请联系经理或对应角色处理。

**7. 翻页/筛选后数据未变化**
确认点击了「查询」；切换筛选条件后页码会自动回到第 1 页。

**8. 中文/English 切换后个别内容仍是英文**
其余语言（西班牙语、德语、法语、日语等）暂时回落到英文界面，属已知情况。

## 十六、日常操作建议

1. **当天线索当天建档**：新建客户后来源、电话务必填全，便于后续统计与提成核算。
2. **勘测及时提交**：草稿不会进入工程师待办，客户等不到方案。
3. **报价先审后发**：未审批的报价不要直接发给客户，避免价格口径不一致。
4. **成交后立即转单**：只有转单后交付、财务才会启动，拖延会影响交付周期和提成结算。
5. **转介绍客户要标注来源**：来源为「转介绍」时不计销售提成，但会计入转介绍奖励，填错会影响双方结算。
6. **每周核对台账**：确认客户回款与未回款，提前催收，避免影响提成发放。
7. **工单描述写清型号与现象**：附订单号/项目名，交付同事能更快定位。
